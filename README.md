# Bday Wish

A cinematic birthday-wishing website made to help someone special feel truly celebrated. It combines a cherry-blossom aesthetic with smooth scrolling, layered parallax scenes, surprise interactions, an animated letter, and a light/dark garden experience.

## Live website

### [just-to-make-you-feel-special.vercel.app](https://just-to-make-you-feel-special.vercel.app)

## Highlights

- Smooth Lenis scrolling with GSAP-powered scroll choreography
- Cherry-blossom parallax scenes and floating petals
- Interactive birthday letter and surprise moments
- Animated cake, candles, confetti, and gallery reveals
- Light and dark visual modes
- Responsive layout for phones, tablets, and desktops
- Reduced-motion support for accessibility

## Built with

- Next.js 16
- React 19
- TypeScript
- GSAP and ScrollTrigger
- Lenis smooth scrolling
- Custom CSS animations
- Vercel

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production build

```bash
npm run build
npm start
```
